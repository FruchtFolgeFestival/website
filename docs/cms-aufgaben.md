# Was im CMS noch zu tun ist

Diese Liste ist für die **Redaktion**. Hier steht, welche Inhalte noch fehlen oder überarbeitet werden müssen, und **wo im CMS** du sie findest. Wie das CMS grundsätzlich funktioniert, steht in [redaktion.md](redaktion.md).

**So arbeitest du die Liste ab:**

1. Im CMS anmelden: <https://dev-fruchtfolge.technik-7e1.workers.dev/admin> (nach dem Domain-Umzug: <https://fruchtfolge.live/admin>)
2. Den genannten Bereich öffnen, Text ändern, **Speichern**
3. Nach 1–3 Minuten in der Vorschau prüfen: <https://dev-fruchtfolge.technik-7e1.workers.dev>
4. Einem Admin Bescheid geben, damit er es veröffentlicht

Platzhalter erkennst du an **`[BITTE ERGÄNZEN: …]`** oder **`[BITTE PRÜFEN: …]`**. Ersetz sie durch echten Text oder lösch sie, wenn es dazu nichts gibt. Wenn du eine Aufgabe erledigt hast, gib einem Admin Bescheid. Er hakt sie hier ab.

## A. Vor dem Go-live erledigen

Diese Stellen sind auf der öffentlichen Seite sichtbar oder blockieren die Veröffentlichung.

### A1. Datenschutzerklärung freigeben (Vorstand)
**CMS:** Rechtliches → **Datenschutz**

- [ ] Alle `[BITTE ERGÄNZEN]`/`[BITTE PRÜFEN]`-Stellen klären (13 Stellen): Datum der Freigabe, Datenschutzbeauftragte:r, Cloudflare-Vertrag und Speicherdauer, Google-Workspace-Vertrag, Löschfristen, Eventfrog, Link zur Datenschutzerklärung der App, Redaktionsbereich, Rechtsgrundlage für Fotos, Anschrift der Aufsichtsbehörde.
- [ ] Wenn der Vorstand den Text freigegeben hat: Schalter **„Entwurf (noch nicht freigegeben)“ ausschalten** und speichern.
- **Wichtig:** Solange der Schalter an ist, kann die Webseite **nicht** veröffentlicht werden. Das ist eine Absicherung.
- Hilfe: [datenschutz-checkliste.md](datenschutz-checkliste.md)

### A2. Mitmachen
**CMS:** Seiten → **Mitmachen**

- [ ] **Kurztext Helfer:innen (Startseite):** ein bis zwei Sätze, wofür ihr Helfer:innen sucht. *Dieser Text steht auch auf der Startseite!*
- [ ] **Text → „Helfer:in werden“:** Welche Aufgaben gibt es (z. B. Aufbau, Bar, Einlass, Awareness, Abbau)? Wann wird Hilfe gebraucht?
- [ ] **Text → „Helfer:in werden“:** Was bekommen Helfer:innen (z. B. Freiticket, Essen, Crew-Shirt)?
- [ ] **Text → „Mitglied werden“:** Wie hoch ist der Mitgliedsbeitrag? Gibt es einen Aufnahmeantrag?
- Die Überschriften „Helfer:in werden“ und „Mitglied werden“ bitte nicht umbenennen. Die Startseite verlinkt darauf.

### A3. Galerie

- [ ] **Fotos:** Bei allen **9 Fotos** das Feld **„Foto von“** ausfüllen (steht noch auf `[BITTE ERGÄNZEN]` und ist in der Galerie sichtbar).
